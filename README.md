## 🚀 Featured Hands-on Demo: Linux Permission Remediation

The [Linux permissions module](./04-linux-permissions/) includes a Bash script that creates a mock lab, checks file and directory permissions, and applies the remediation rules described in its documentation.

```bash
git clone https://github.com/UNG-Seangeang/Cybersecurity_portfolio.git
cd Cybersecurity_portfolio/04-linux-permissions
chmod +x remediate_permissions.sh
./remediate_permissions.sh --setup-demo
```

Run the script only in a test environment where you understand the files and permission changes it will make.
