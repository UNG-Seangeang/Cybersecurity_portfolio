# Network Analysis — Learning Module

## Purpose
This module is reserved for documented network reconnaissance and packet-analysis exercises. The goal is to learn how to establish a baseline, interpret network services, inspect packet metadata, and explain security implications.

## Tools to practice
- **Nmap:** scan only systems you own or have explicit permission to assess.
- **Wireshark:** capture and inspect traffic in an isolated lab.
- **TCP/IP:** interpret addresses, ports, protocols, and connection behavior.

## Evidence to add after completing a lab
1. Lab topology and authorization/scope.
2. Exact Nmap command and sanitized output.
3. Packet-capture filters and relevant screenshots or exported packet details.
4. Observations separated from assumptions.
5. Risk explanation and practical mitigation.

## Current evidence status
This README is a project guide, not a record of a verified scan. No open ports or suspicious traffic are claimed here until supporting lab output is added.

## Safety
Do not scan public or third-party systems without written authorization. Use a private virtual lab or an explicitly approved target.
